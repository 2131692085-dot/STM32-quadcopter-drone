# STM32-quadcopter-drone

基于 **STM32F103C8T6 + FreeRTOS** 的微型四轴无人机项目，包含**飞控板**与**遥控器板**两个完整工程，通过 SI24R1（nRF24L01 兼容）2.4G 无线链路通信，实现姿态自稳飞行。

## 系统架构

```
┌─────────────── 遥控器板 rc/ ───────────────┐         ┌──────────────── 飞控板 drone/ ────────────────┐
│ 摇杆 ADC+DMA 采样（4路）                    │         │ SI24R1 收包轮询（10ms）+ 三层校验              │
│ 按键扫描：短按微调 / 长按摇杆中位校准        │  2.4G   │ 飞行状态机 IDLE/NORMAL/HOLD_HEIGHT/FAULT       │
│ 数据处理：归一化 / 中位补偿 / 值域保护       │ ──────→ │ MPU6050：零偏校准 → LPF/Kalman → 四元数解算    │
│ SI24R1 广播 17 字节数据包（6ms 周期）        │ 单向链路 │ 串级 PID（角度环→角速度环，6ms 控制周期）      │
│ 电源心跳：IP5305T 防自动关机                │         │ 电机混控 → 4路 PWM（AO3400 + 空心杯）          │
└────────────────────────────────────────────┘         └───────────────────────────────────────────────────────┘
```

## 核心特性

- **串级 PID 姿态控制**：外环（角度）+ 内环（角速度），6ms 控制周期，ki=0（稳态误差源已在传感器校准与解算补偿中消除）
- **姿态解算**：四元数法 + 加速度计互补修正；陀螺仪走一阶低通（α=0.15），加速度计走标量卡尔曼（Q=0.001 / R=0.543，稳态增益 ≈0.04）
- **MPU6050 零偏校准**：上电静置判定 + 400 点滑动平均，积分器直流分量前置消除
- **自定义通信协议**：17 字节负载（目的地址标识 + 控制数据 + 累加和校验），飞控端以 500ms 滑动窗口维护连接状态，失联自动进入 FAULT 态
- **飞行状态机**：IDLE（待解锁）→ NORMAL（受控飞行）→ HOLD_HEIGHT（定高）→ FAULT（失联保护），油门解锁手势防误触
- **FreeRTOS 任务设计**：双板各 4 任务，`vTaskDelayUntil` 绝对周期；关键共享数据临界区保护

## 目录结构

```
├── drone/    飞控板工程（CubeMX + Keil MDK5）
│   ├── drone_tasks/   FreeRTOS 任务层（Motor/Comm/LED/Power）
│   ├── Interface/     SI24R1、MPU6050、LED 等板级驱动
│   ├── Common/        PID、滤波（LPF/Kalman）、四元数解算
│   └── App/           应用层（电机混控、数据处理）
└── rc/       遥控器板工程
    ├── rc_tasks/      FreeRTOS 任务层
    ├── Interface/     SI24R1、摇杆 ADC、按键、OLED 驱动
    └── App/           协议打包、校准与微调逻辑
```

## 构建与烧录

- Keil MDK 5.38（ARMCC / AC5），分别打开 `drone/MDK-ARM/*.uvprojx` 与 `rc/MDK-ARM/*.uvprojx`
- 硬件：STM32F103C8T6 最小系统 + SI24R1 模块 + MPU6050（I2C1: PB6/PB7）+ 380 空心杯电机 ×4
- 调试接口：SWD（CN1），串口 1 输出 VOFA+ FireWater 格式数据用于波形观测与姿态球显示

## 通信协议要点

| 字段 | 内容 |
|---|---|
| Byte 0-2 | 目的地址标识（防串台） |
| Byte 3-9 | 姿态命令（pitch/roll/yaw 0~1000）+ 油门 + 按键命令 |
| Byte 10-16 | 累加和校验 |

遥控器以 6ms 周期无条件广播（零握手、上电即通）；飞控端校验收包标志 → 目的地址 → 累加和三层过滤，连续 500ms 无有效包判定失联。
